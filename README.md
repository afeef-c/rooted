Rooted Stores
Rooted Stores is a full-featured e-commerce platform built with Django. It provides a seamless shopping experience with secure payments, user authentication, and scalable deployment.

Features
User Authentication: Secure sign-up, login, and password management.
Product Listings: Add, update, and manage products with detailed descriptions and images.
Shopping Cart: Add products to the cart and update quantities.
Order Management: Place, track, and manage orders with secure payment integration.
Secure Payments: Integrated with Razorpay for reliable and secure transactions.
Scalable Deployment: Deployed on AWS to handle large traffic and ensure high performance.
Tech Stack
Backend: Django
Frontend: HTML, CSS, Bootstrap
Database: PostgreSQL
Payment Gateway: Razorpay
Deployment: AWS
